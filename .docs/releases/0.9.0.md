# Realmkeeper 0.9.0 — A living, readable Realm

## Summary

A connected fantasy Realm makes real agent activity easier to survey and inspect,
while Monitor remains the primary operational workspace. Character artwork and
scale are preserved.

## What changed

- Six painted districts, connected terrain, integrated courtyard surfaces,
  grounded landmarks, and quieter decorative furniture and HUD panels.
- Stable agent seats and overflow annexes support dense fleets without reshuffling
  peers. Compact layouts and terrain expansion preserve navigation and placement.
- Workstations reflect observed working, blocked, stale, quiet, attention, and
  ended states. An ended session is not presented as proof of task success.
- Character and station inspection connects agents to district context and
  explicitly linked runs; next-ask navigation keeps blocking requests accessible.
- Selected activity labels get placement priority, selection rings remain legible
  at overview zoom, and explicit focus frames agents beside inspectors.
- Canvas gesture guards prevent HUD click-through. Optional Herdr integration is
  isolated in desktop tests. Packaged-executable E2E is supported.

## Distribution and limitations

- Download the Apple Silicon macOS DMG attached to this release.
- This build is **unsigned and not notarized**; macOS may display a Gatekeeper
  warning. It is not a signed public-distribution release.
- No Intel, Windows, or Linux installers, and no automatic updates.
- Provider controls remain capability-gated. Fixture regressions do not establish
  support for unprobed live provider versions or unavailable control APIs.
- No dependency upgrades or persisted-state migrations in this release.
